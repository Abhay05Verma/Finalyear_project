# Finalyear_project
An IoT &amp; ML-based Landslide Early Warning System for real-time monitoring, prediction, and disaster prevention.
Landslide Early Warning System (LEWS) 🌍⛰️

A smart IoT and Machine Learning-based Landslide Early Warning System designed to detect and predict potential landslides in vulnerable areas. This system collects real-time environmental data such as rainfall, soil moisture, vibration, temperature, humidity, and slope movement using sensors and processes the data through Machine Learning algorithms (Random Forest) to analyze landslide risk levels.

The system provides early alerts and warnings to help reduce damage and improve public safety. It includes real-time monitoring, data visualization, risk prediction, and alert notifications for disaster prevention and management.

Features

✅ Real-time sensor data monitoring
✅ Machine Learning-based landslide prediction
✅ Random Forest algorithm for accurate analysis
✅ IoT sensor integration
✅ Early warning alert system
✅ Data storage and visualization
✅ Web-based monitoring dashboard

Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MySQL / Sequelize ORM
Machine Learning: Python, Random Forest
IoT Hardware: Sensors, Microcontroller/ESP32 or NodeMCU

Goal: To minimize landslide risks by providing timely warnings and helping authorities and communities take preventive actions.
